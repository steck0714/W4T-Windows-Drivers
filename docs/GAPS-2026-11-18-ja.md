# 不足点の点検(2026-11-18)と対処

| 不足 | 区分 | 対処 / 次 |
|---|---|---|
| L4T 表示ドライバ(DC/SOR/DP/HDMI/EDID/リンク学習)一式が手元に無かった | 再配布OK(GPL-2.0) | **`reference/nvidia-dc/` に全体を無改変で取り込み**(151 ファイル、固定コミット付き) |
| ATF の T210 プラットフォーム一式(PSCI/SC7/PMC) | 再配布OK(BSD-3) | **`reference/atf/plat-nvidia-tegra/`** |
| hekate の L4T 起動(SC7 ファーム受け渡し) | 再配布OK(GPL-2.0) | **`reference/hekate-l4t/`** |
| PEP の枠組み(Tegra X1 の PEP の土台) | 再配布OK(**MS-PL**。GPL と非互換 → 別ライセンスの同梱物) | **`reference/ms-pep/`**(Microsoft `pofx/PEP`) |
| `sc7entry.bin` / `sc7exit.bin` | 再配布不可(NVIDIA) | fwfetch に追加。実機の SD の `bootloader/sys/l4t/`(hekate 配布物)から取り出す。`sc7exit` は Erista では hekate が起動時に**自分の eMMC の pkg1 から RSA 係数を書き込む**ので、利用者の実機が一次ソース |
| T210(Erista)用 XUSB ファーム | 再配布不可(NVIDIA) | fwfetch に `xusb_t210`(`tegra21x_xusb_firmware`)を追加。**Erista プロファイルに bl31 / XUSB が抜けていたのも修正** |
| `bpmpfw*.bin` / `mtc_tbl_b01.bin` | — | T210 では不要(hekate `l4t.c`)。`not_needed` に理由を記載 |
| LineageOS の bl31 | 再配布不可 | 既存の bl31 取り出しで対応済み(Switchroot の SD から) |
| EDID パーサ、DPAUX、リンク学習、SOR/DC レジスタ手順 | 実装 | HDMI 後半(PROGRESS.md の次) |
| PEP 本体(SC7 に落とす) | 実装 | `reference/ms-pep/` を土台に、実機でブート確認できてから |
| Nintendo の著作物(Horizon FW・鍵) | 使わない | `not_needed` のとおり、必要な根拠は見つかっていない |
